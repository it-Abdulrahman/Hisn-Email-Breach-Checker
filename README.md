# 🛡️ Hisn — Email Breach Checker

A privacy-focused web application that checks whether an email address has appeared in known data breaches and provides a security score with recommendations.

## 🚀 Features

- 🔒 Privacy-first architecture
- No email storage
- No server-side logging
- Stateless application design

- 🛡️ Security Score System
- Rates email security from 1-10
- Provides recommendations based on breach data

- ⚙️ Abuse Protection
- IP-based rate limiting
- Protection against automated requests

- 🌐 Bilingual Support
- Arabic / English
- RTL / LTR dynamic interface

## 🛠️ Technologies

- Node.js
- Express.js
- HTML
- CSS
- JavaScript
- XposedOrNot API

## 🚀 Deployment

Deployed using Render with GitHub continuous deployment.
